# Book movement — macro observations above H3 flow

H3 flow answers: *what clauses are there, and what hangs from what?*

Book movement answers: *what keeps returning, what is added each time, and where
several threads come together?*

Never “theme.” Never auto-create an H2 from one weak signal.

---

## Philosophy

1 John often **returns** to a claim with added pressure — not a string of isolated
topics. Subject change or a single imperative is too weak to open a movement.

The app **shows objective recurrences** so the student is not staring at a blank
strip. It does **not** name sections (Light / Love / Antichrist) or place H2s.

H2 remains a student decision: a sustained stretch where returning threads are
developed together. Candidate boundaries only appear where **several independent
observations converge** (≥ 3 signal kinds).

---

## Outputs

### 1. Writing-purpose statements

Clauses that say *why* John writes/announces (escribo / escribimos / he escrito /
anunciamos + para que / acerca…). Listed together as a letter-long trajectory —
not as section titles.

### 2. Vocatives and audience resets (“Possible discourse reset”)

Strong reorientation signals: Hijitos, Amados, Hermanos, Niñitos, writing
formulas, “este es el mensaje”, “y ahora”, “última hora”, major redirecting
imperatives. Marked as **Possible discourse reset** — never automatically an H2.

### 3. Repeated opening formulas

Exact / near-exact pattern families, each occurrence linked to prior ones:

- el que dice / si decimos
- en esto
- todo el que
- sabemos / conocemos
- les escribo / les he escrito
- permanece
- el que ama / aborrece
- nacido de Dios

### 4. Repeated words (primary vocabulary map)

Folded LBF Spanish **content-word** frequency across the book (not curated fields).

- Tokenize verse text; drop stopwords (articles, pronouns, common connectives).
- Keep surfaces with **≥ 3** hits in **≥ 2** distinct verses.
- Show verse chains; mark **return** when a word reappears after a gap.
- Example: *comunión* must appear here even though it is not in a semantic family.

Never labels these as themes.

### 5. Semantic families (secondary)

Curated families (LIGHT, FAMILY, ABIDING, TRUTH, LIFE, WORLD, LOVE) remain as a
secondary return map — useful clusters, not the primary inventory. Prefer
repeated words when a frequent surface is missing from the families.

### 6. Contrast observations (student)

Student-marked pole pairs on a verse (e.g. luz / tinieblas, comunión / tinieblas).
Stored in progress; shown on the Movement verse dashboard. The app does **not**
hand out a contrast-theme map or pole titles.

Quiet engine co-occurrence (luz+tinieblas in one span, etc.) may still add
evidence — never as a named theme browser.

### 7. Convergence points

Where multiple recurring signals co-occur in a short stretch. These feed
**candidate large boundaries** only when ≥ 3 signal kinds agree at a seam.

## Development (Movement dashboard)

For the selected verse, assemble observational subsections (omit when empty):

| Subsection | Sources |
|---|---|
| **Tension** | Student pressure into the verse; student contrasts; engine contrast evidence |
| **Pressure** | Student `pressureAfter` marks that bear on this verse (mark/clear) |
| **Argument** | Writing-purpose / statement claim + reason frames that ground the anchor H3 |

No auto titles; captions stay observational.

---

## Candidate large boundary rule

Suggest a quiet **Candidate boundary** (not an H2) only when at least three of:

- authorial reset / new vocative / writing formula
- writing-purpose statement
- dominant formula family change
- vocabulary field cluster change (sustained) or repeated-word return cluster
- mood or recipient change for a sustained run
- prior pressure / cycle sense (student mark or later)

One signal alone never creates a candidate. Subject change alone is too weak.

## Relation to Skeleton

words, semantic families). **Movement** is a dedicated Structure view: verse
convergence, dashboard, development panel, verse text — blank **Your H2**.
